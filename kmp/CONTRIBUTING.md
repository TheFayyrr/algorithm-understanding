# 贡献说明

欢迎通过 Issue 提出看不清楚的步骤、算法错误或新的演示需求，也欢迎提交 Pull Request。

## 新增一个算法

1. 使用独立的英文小写文件夹，例如 `binary-search/`、`sliding-window/`。
2. 提供 `index.html`、算法逻辑、动画界面、样式和 `README.md`。
3. 算法逻辑与界面分开，让算法可以独立运行和检查。
4. 在根目录 `index.html` 和 `README.md` 中加入入口。

每个演示至少包含一个完整例子，说明变量的含义、初始化、每次更新和结束条件。动画应支持播放、暂停和逐步查看。

## 界面与代码

- 保持浏览器直接打开即可运行，不要求安装前端依赖。
- 使用相对路径，适配仓库子路径和 GitHub Pages。
- 使用文字或标记辅助颜色，让含义不依赖颜色辨认。
- 保留键盘操作、移动端布局和减少动态效果的支持。
- 为算法添加能独立判断正确性的例子或检查；避免仅复述实现的测试。
- 引用外部资料时标明出处，不提交未经许可的整篇文章、图片或视频。

提交前运行 README 中适用的检查，并在 PR 中说明变化和验证结果。
