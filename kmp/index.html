本动画使用的 i、j 和 next 约定

下标从 0 开始。next[i] 表示 P[0…i] 的最长相等真前后缀长度。j 表示已有相等或匹配的长度，也是前缀或模式串下一待比较字符的下标。

比较失败且 j 大于 0 时，i 保持不动，j = next[j − 1]。生成 next 的最后一步中，i 停在 f，j 从 2 回退到 1，再回退到 0。

文本匹配成功前，本动画已经前进 i，因此起始下标为 i − j。
